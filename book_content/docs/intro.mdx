## Who this book is for

This book is for students, engineers, founders, and technical instructors who want a structured path into Physical AI. You should be comfortable with Python fundamentals, basic AI concepts, and command-line development. Robotics experience helps, but the course introduces the major tools from first principles.

## What you will learn

By the end of the course, you should be able to:

- Explain Physical AI and embodied intelligence in practical terms.
- Use ROS 2 concepts such as nodes, topics, services, actions, launch files, and parameters.
- Model robots and environments with Gazebo, Unity, URDF, and SDF.
- Understand NVIDIA Isaac Sim, Isaac ROS, VSLAM, Nav2, synthetic data, and sim-to-real constraints.
- Design Vision-Language-Action workflows that connect speech, planning, perception, navigation, and manipulation.
- Evaluate hardware and cloud lab tradeoffs for RTX workstations, Jetson kits, RealSense cameras, IMUs, microphones, and robot platforms.

## Chapter standard

Each chapter follows a consistent pattern:

- **Learning outcomes**: What you should be able to explain or build.
- **Concept explanation**: The core ideas, vocabulary, and tradeoffs.
- **Visual model**: A diagram, flow, table, or system map.
- **Practical lab**: A task that turns reading into practice.
- **Quiz**: Short checks with answers.
- **Safety and hardware notes**: Constraints for simulation, edge devices, and physical robots when relevant.

## Capstone outcome

The capstone is a simulated humanoid robot that receives a voice command, forms a plan, navigates around obstacles, identifies an object with computer vision, and manipulates it. The first implementation can run in simulation; physical deployment requires additional safety review, local edge execution, and latency-aware design.
